# Windows 真实桌面验收记录

2026-11-11，使用已打开的 DeepSeek Harness 与 CodeArts 原生桌面客户端，通过官方自定义 MCP 连接器完成实际模型派发、执行及独立验收。测试在两端已有的同一个鸿蒙游戏工作区内使用独立子目录。

| 环境 | 本次范围 |
| --- | --- |
| DSH 桌面 | 包版本 0.2.2-rc.1、EXE 产品版本 0.2.2.0，使用当前配置的模型与原生工具 |
| CodeArts 桌面 | 0.2.9，使用原生文件与终端工具 |
| 通信 | 两个本机 stdio MCP 角色与同一个 SQLite 队列 |
| 执行器 Python | 本机已有的 Python 3.13.14 |
| 独立复核 Python | DSH 自带运行时 Python 3.12.14 |

| 场景 | 实际过程 | 结果 |
| --- | --- | --- |
| 正常交付 | DSH 提交任务；桌面手动领取，创建 `calc.py`、`test_calc.py`、`hello.txt` 并运行三个用例 | CodeArts 实际测试 3/3 通过，回报交付 |
| 自动通知与验收 | 交付通知送到原 DSH 会话；DSH 读取文件、换用自身解释器重跑三项测试并逐字节核对标记 | 原会话写出复核文件并调用 `review_delivery`，任务为 `accepted` |
| 退回修订 | 执行器按负向测试要求交付 `NEEDS_FIX`；DSH 独立读取后退回，下一次手动领取使用新键 | 同一任务按反馈修改为 `FIXED_OK`，重新交付并通过 DSH 独立验收 |
| 排队取消 | DSH 通过 MCP 提交新任务后立即取消，再查询状态 | `canceled`，对应的待执行文件未产生 |
| 空队列 | CodeArts 用新的领取键实际调用 `claim_next`，将真实返回保存为观察记录 | `task: null`、`busy: false`，提示先让 DSH 提交任务 |

主控还独立运行了交付的三项用例并核对标记文件。私有证据包含任务状态快照、执行器回报、DSH 验收证据、文件哈希和主控复跑结果。

本次实测中，两个桌面终端的 `python`/`py` PATH 与接入脚本的运行环境不同，使用各自明确的解释器绝对路径完成测试。派发条件准备阶段曾出现字节计数误写，错误任务取消后使用新请求键重提。项目补充了相应错误提示与操作说明。

DSH 原生沙箱启动曾出现 Windows `SetNamedSecurityInfoW / Win32 5` 权限失败。通过客户端原生确认，在备份后补齐当前用户对本机游戏工作区的控制权限，再继续运行。ACL 备份与回滚脚本保存在私有验收目录，实际文件与终端权限仍由所用客户端及操作系统决定。

初版检查以会话接口模拟和模型调用前截获为主，遗漏了消息 `role` 字段检查。本次补上真实 inbox 入队验证，并完成上述真实模型闭环。自动化回归还覆盖交付回执重试、领取键重放、旧库兼容及共享连接器卸载等已复现问题。

原始截图、账户配置、完整会话、项目路径和运行数据库保存在开发者本机。本文记录可公开的行为和验证范围。其他版本、其他桌面系统及长期运行需要相应环境验证。
