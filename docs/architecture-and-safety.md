# 架构、数据与账号风险

## 两个 MCP 角色与一个队列

DSH 和 CodeArts 桌面各自启动一个 Python stdio MCP 进程，两个进程打开同一个本机 SQLite 文件。SQLite 的写事务与唯一请求键用于协调重复提交、并发领取和任务状态更新。

派发端提供 `submit_task`、`queue_status`、`review_delivery`、`cancel_task`。执行端提供 `claim_next`、`report_progress`、`report_delivery`。工具角色划分操作界面，系统访问权限仍由当前操作系统用户及客户端设置决定。

任务的主要流程为 `queued → running → awaiting_review → accepted`。受阻任务进入 `needs_attention`，退回任务重新进入 `queued`，取消任务进入 `canceled`。执行中的任务保留一个归属令牌。领取过期时由用户核实执行状态，之后继续原任务或确认停止再重新派发。

## 交付通知

DSH 插件观察成功的提交工具事件，记录任务 ID、原 DSH 会话、profile 和通知版本。约两秒一次的本机查询查找 `awaiting_review` 和 `needs_attention`。父端核对当前状态后，分别处理独立验收或受阻事项。

已经加载的会话通过 `agent.followup` 接收下一轮消息。持久会话通过 DSH 自带的会话组合服务恢复，再接收通知。该恢复使用 `sessionController.agents.resolveAgent`，与当前 DSH 预览版本的宿主接口有关。升级宿主后应重新验证恢复路径。

本地租约协调同时运行的通知实例，交付时间戳用于去重。启动通知以后，DSH 仍应先核对最新队列状态，再决定实际检查操作。模型运行错误、权限不足、会话恢复失败或进程崩溃时，可以通过 `queue_status` 和实际文件继续核查。

alpha.6 在会话恢复后按当前通知租约核对归属并续期，回执与失败处理也校验该租约。旧实例恢复过晚或失败过晚时，会保留新实例的处理状态。错误退避从实际失败时间计算。崩溃恢复和模型侧错误仍需要结合任务当前状态处理。

## 数据与模型服务

| 内容 | 保存或处理位置 |
| --- | --- |
| 任务标题、指令、标准、项目路径、进度、交付、验收证据 | 本机 `queue.sqlite` |
| 任务归属会话、通知去重、恢复错误 | 本机 `review.sqlite` |
| 配置原文和恢复清单 | 本机 `backups` |
| 华为账号登录、凭据保存、模型调用、计费 | CodeArts 官方客户端及对应服务 |
| DSH 检查轮次的上下文、文件访问与模型调用 | DSH 及其当前选择的模型服务 |

CodeArts 从本机任务中取得的指令，以及 DSH 后续读取的代码或报告，可能进入对应模型服务的正常请求上下文。敏感项目应结合客户端、模型服务和本机权限设置评估数据使用范围。

`lease_token` 表示本机任务归属。它用于同一执行任务的进度与交付调用，含义与华为登录凭据分别定义。任务库、日志与配置备份适合保存在受控本机目录，公开问题反馈应先清理项目内容和路径。

## 文件与执行权限

本机运行源码、Python 环境及队列目录应使用与实际运行身份匹配的访问名单。安装目录继承通用用户组的修改权限时，其他具备相应本机权限的进程可能修改任务或运行脚本。调整前保存原 ACL，并保留当前用户、系统和实际使用的开发工具身份，调整后核对数据库及 WAL/SHM 文件的访问和两个客户端的真实读写。

用户可以通过 CodeArts 原生定时任务自动启动领取。每轮依然使用相同的项目范围、归属令牌、交付与独立验收流程。当前工具版本兼容手动与用户授权的原生定时运行。计划设置和权限范围见自动领取说明。[原生定时自动领取](automation.md)

提交时项目目录必须已经存在并采用绝对路径。交付时解析并核对实际路径，路径需要落在该项目内且已经存在。

领取时可用 `project_dir` 筛选当前工作区及子目录的任务。该参数选择队列记录，实际文件与终端访问遵循客户端及操作系统权限设置。

这项校验覆盖回报的交付路径。CodeArts 原生文件、终端等工具的实际权限由桌面客户端控制。DSH 独立验收的权限由其自身配置控制。用户应在客户端确认项目、操作范围和必要权限，文件结果应按项目原有测试与版本管理方式检查。

运行任务取消需要结合桌面执行情况确认。安装器只更新本项目负责的配置入口，修改前保存私有备份，文件替换时检测并发修改。原始 YAML 格式和注释由备份保留。

## 华为账号风险的判断范围

华为官方公开支持自定义本地 MCP 连接器。本项目通过这一入口在桌面领取任务，并使用原生工具完成工作。登录、模型调用和额度计算由官方客户端处理。结合当前实现，账号风险被判断为较低，这属于基于实现和公开文档的推断。[官方连接器文档](https://support.huaweicloud.com/usermanual-codeartsdesktop/desktop_0015.html)

官方要求用户评估第三方 MCP，自行承担其使用风险。服务声明 2.5.7 涉及逆向及自动提取模型输出的限制，2.7.3 说明 MCP 框架风险，2.7.7 约定违约可暂停或终止服务。公开资料对这套具体任务交接实现的合规边界与账号处置缺少专门确认，风险概率仍有不确定性。[CodeArts 服务声明](https://www.huaweicloud.com/declaration/tsa-codearts-doer.html)

## 验证与披露

软件测试能检查队列、配置处理和通知逻辑。账号处置由平台规则及实际使用决定，完整桌面模型执行也需要在相应真实环境验证。当前记录应与发布版本一起阅读。[验证范围](verification.md)

公开安全问题时，可先在 GitHub 提交去除敏感细节的简要报告，并说明影响与复现环境。涉及个人账号、项目代码或凭据的资料应保存在你自己的受控位置，后续按仓库维护者提供的沟通渠道处理。
