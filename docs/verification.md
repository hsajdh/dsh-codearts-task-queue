## 自己复查

```powershell
.\.venv\Scripts\python.exe scripts/configure.py --doctor --profiles desktop
.\.venv\Scripts\python.exe -m unittest discover -s tests -p "test_*.py" -v
node --test tests/test_review_relay.mjs
```

静态检查核对本机配置与已有数据库完整性。自动化测试运行临时 MCP 进程与模拟交付，使用自身的测试文件。桌面完整执行应按 README 的小任务示例单独进行，并记录执行版本、交付文件、实际命令与 DSH 独立验收证据。
